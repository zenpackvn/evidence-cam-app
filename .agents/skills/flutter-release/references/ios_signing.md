# iOS Signing

## Manual setup

1. Create an App ID in [Apple Developer Portal](https://developer.apple.com/account)
2. Create a Distribution certificate (or use automatic signing in Xcode)
3. Create a Provisioning Profile (App Store Distribution)
4. In Xcode: Runner → Signing & Capabilities → select team and profile

## Fastlane Match (recommended for teams)

Fastlane match stores certificates and profiles in a private git repo or cloud storage, keeping the team in sync.

```ruby
# ios/fastlane/Matchfile
git_url("https://github.com/your-org/certificates")
storage_mode("git")
type("appstore")
app_identifier("com.example.app")
```

```bash
# First time — generate certificates
fastlane match appstore

# CI — read-only mode (never creates new certs)
fastlane match appstore --readonly
```

## `ios/ExportOptions.plist`

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
  "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>method</key>
  <string>app-store</string>
  <key>teamID</key>
  <string>YOUR_TEAM_ID</string>
  <key>uploadBitcode</key>
  <false/>
  <key>uploadSymbols</key>
  <true/>
  <key>signingStyle</key>
  <string>manual</string>
  <key>provisioningProfiles</key>
  <dict>
    <key>com.example.app</key>
    <string>match AppStore com.example.app</string>
  </dict>
</dict>
</plist>
```

## Rules

- Certificates and provisioning profiles must be valid at release time — check expiry.
- CI uses `fastlane match appstore --readonly` to avoid accidentally creating new certs.
- `ExportOptions.plist` references the exact provisioning profile name generated by match.
